データ整備

フリガナの修正を本体データ（furigana-overrides.json）へ反映するためのページです。通常の利用では開く必要はありません。

GitHub token

fine-grained personal access token をこのブラウザの localStorage に保存します。 必要な権限は、このリポジトリに対する Contents: Read and write だけです。

保存したトークンは、このブラウザで動く JavaScript から読める状態に置かれます。 共用端末では使わず、有効期限を短く設定し、使い終わったら削除してください。

使い方

  • ここでトークンを保存します。
  • アプリの設定で「カード詳細にフリガナ編集欄を表示」をオンにします。
  • カードを拡大表示するとフリガナの入力欄が出るので、修正して Save を押します。

保存に失敗する場合は、トークンの権限と有効期限を確認してください。
